# Editar las experiencias de Skills

Modificá `src/data/skillExperience.json`. Cada categoría contiene tecnologías y un texto corto de experiencia real (proyectos o contexto). No se usan porcentajes.

Ejemplo: `"React": "ValenOS · ValenShop"`.

Para sumar una tecnología, agregá otra entrada dentro de su categoría. Para cambiar qué proyectos aparecen, editá su texto.

Los ejecutables simulados y las ventanas independientes se mantienen.
